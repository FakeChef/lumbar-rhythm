# 腰椎节奏 / Lumbar Rhythm

腰椎节奏 / Lumbar Rhythm 是一个永久免费、无广告、无账号、无云端上传的腰突术后康复日志 App，面向需要本地记录康复活动、坐站节奏、症状变化、康复节点和报告回顾的用户。

当前仓库已创建 Flutter 移动 App 骨架，Flutter 项目名称为 `lumbar_rhythm`，目前仅计划开发 Android 应用。

本项目希望帮助用户建立更稳定的日常活动节奏：减少长时间保持同一姿势，记录个人状态变化，并通过温和提醒支持自我管理。它不是医疗器械，也不替代专业医疗服务。

## 项目简介

Lumbar Rhythm 以“本地优先、简单可靠、长期可用”为核心设计方向。App 围绕术后康复日志、坐站提醒、每日康复记录、康复节点和本地报告，帮助用户回顾自己的康复之路。

项目关注的不是复杂诊断，而是可持续的提醒与记录体验。所有健康相关数据默认保存在用户本地设备中，用户不需要注册账号，也不需要将个人健康数据上传到云端。

## 产品原则

- 永久免费，不设置订阅、付费墙或隐藏收费功能。
- 无广告，不接入广告系统或广告追踪 SDK。
- 无账号，不要求用户注册、登录或绑定第三方身份。
- 无云端上传，健康记录和提醒设置默认保存在本地设备。
- 本地优先，核心功能应在离线状态下正常可用。
- 克制设计，避免制造焦虑，不以恐吓、诊断或疗效承诺引导用户。
- 用户可控，支持导出数据和删除全部本地数据。

## 核心功能

- 久坐久站提醒：作为基础工具记录坐、站、走、休息状态，并按当前状态安排本地提醒。
- 每日康复动作记录：基于内置动作模板记录完成量、单位、做后反应、症状标签和备注。
- 每日康复小结：记录总体感觉、腰部不适、腿部症状、疲劳感和备注。
- 康复节点：记录第一周、第一个月、复诊、复工复学和阶段回顾等节点。
- 本地报告：汇总康复活动、坐站节奏、症状变化和康复节点，仅用于个人回顾。

当前基础页面包括：

- 首页。
- 康复节点页。
- 报告页。
- 设置页。

## 医疗边界

本 App 是健康提醒和自我记录工具，不是医疗器械，不提供疾病诊断、治疗建议、复发判断、用药建议或手术建议。

App 中的任何记录、提醒、趋势展示或文字说明，都只能作为个人健康管理参考，不能作为医学结论使用。用户如需判断病情、制定治疗或康复方案，应咨询医生、康复师或其他专业医疗人员。

如出现大小便异常、鞍区麻木、进行性下肢无力、术后伤口红肿发热渗液、疼痛突然明显加重等情况，应及时就医。

## 隐私原则

- 不要求注册或登录。
- 不上传健康数据。
- 姿势 session、康复记录和提醒设置保存在本地设备。
- 用户可以导出自己的数据。
- 用户可以删除全部本地数据。
- 不出售、不共享用户数据。
- 不接入广告追踪 SDK。

更完整的隐私说明请参见 [PRIVACY.md](PRIVACY.md)。

## 技术路线

- 使用 Flutter 开发，目前仅计划支持 Android 移动端 App 体验。
- 使用 Riverpod 做状态管理。
- 使用本地数据库保存姿势 session、康复记录和提醒设置。
- 使用本地通知实现久坐久站提醒。
- 采用本地优先架构，核心数据存储在用户设备上。
- 将提醒、记录、设置、数据导入导出等能力模块化实现。
- 重要业务逻辑需要配套测试，尤其是提醒调度、数据保存、数据导出和数据删除。
- 避免引入与产品原则冲突的能力，包括广告、登录、订阅、云同步和第三方追踪 SDK。

## 项目结构

```text
lib/
  app/                         App 入口与全局配置
  core/
    database/                  本地数据库服务
    notifications/             本地通知服务
    theme/                     主题
  features/
    home/                      首页
    records/                   旧记录兼容模块
    recovery/                  康复资料与每日小结
    milestones/                康复节点
    reports/                   报告页
    actions/                   康复页
    settings/                  设置页
    shell/                     底部导航与页面容器
```

## 本地运行

安装 Flutter 后，在项目根目录执行：

```bash
flutter pub get
flutter run
```

本仓库不接入广告、统计、登录、云服务 SDK。后续开发应继续保持本地优先和医疗边界。
